# Case - Crédito e Apostas

Este repositório contém a análise de crédito e apostas, incluindo:
- limpeza e preparação dos dados
- junção de contratos e transações
- análise estatística
- geração de relatórios e gráficos

## Estrutura principal
- `dados/`: arquivos de entrada
- `pipeline_python/`: scripts do pipeline
- `saida/`: arquivos processados
- `graficos/`: visualizações geradas

## Descrição do projeto
Este case foi desenvolvido para analisar a relação entre contratos, transações e apostas, com foco em indicadores de risco e comportamento de crédito.
